# CS452 Kernel Variant Archive

Private source-only snapshots of five distinct CS452 working directories on the University of Waterloo Linux account, captured on 2026-09-21. The public portfolio project is [`cs452-real-time-kernel`](https://github.com/y68wu/cs452-real-time-kernel); these snapshots preserve earlier and experimental variants without overwriting that presentation repository.

| Directory | Source GitLab repository | Notes |
| --- | --- | --- |
| `cs452_tc1_only/` | `y68wu/cs452_tc1_only` | Includes the working-tree state, including 29 uncommitted modifications present at capture time. |
| `cs452_kernel2/` | `y68wu/cs452_kernel2` | Alternative kernel snapshot. |
| `cs452_clean/` | `y68wu/cs452` | Clean baseline snapshot. |
| `cs452_kernel/` | `y68wu/cs452_kernel` | Kernel snapshot. |
| `cs452_kernel3/` | `y68wu/cs452_kernel3` | Alternative kernel snapshot. |

Only source files, headers, build scripts, and text documentation were copied. Git metadata, generated binaries, and media assets are not included, so these folders are archival snapshots rather than guaranteed standalone builds. Original remote folders and GitLab projects were not changed. Student identifiers were redacted in copies. This private archive may include course-provided code and is not represented as wholly original work.
